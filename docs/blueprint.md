# **App Name**: CapWallet

## Core Features:

- Welcome Page: Welcome page with site logo, name, H3 heading, paragraph text, numbered list with icons, and 'Get Started' button. Uses local storage to show only once.
- Sign-Up Page: Sign-up page with full name, username (with availability check using a tool with Firestore), gender selection (with custom input option), country dropdown (with custom input option and country code auto-fill), optional referral code and phone number. Phone number is required when the custom country option is chosen.
- Account Creation Flow: Recovery token generation with modal, Terms of Service agreement with modal (link to 'https://capwallet/terms-of-services.web.app'), and 'Create Account' button upon confirmation.
- Login Page: Login page with input for 'Email, Username or Recovery Token', password input, 'Login' button, and links for 'Forgot password?' and 'Sign Up Now'.
- Forgot Password Page: Forgot Password page with email input, recovery token input, 'Send Reset Link' button, 'Remembered Password' button, and link for 'Lost recovery token?' (mailto: capwallet.recoveraccount@instmail.uk).

## Style Guidelines:

- Primary color: Deep Blue (#293B5F) to inspire security, reliability, and trust.
- Background color: Light Blue (#D6E4EF), a soft and unobtrusive background.
- Accent color: Teal (#3CA6A6), an analogous yet distinctive accent color that contrasts nicely with the primary.
- Font: 'Inter' (sans-serif) for both headlines and body text, offering a modern and readable interface.
- Minimalist, vector-based icons for a clean and modern aesthetic.
- Clean and intuitive layout with a focus on ease of use and accessibility.
- Subtle transitions and animations to enhance the user experience without being distracting.
